# SLK Am Nat reviewer-risk audit V6

## Current verdict

The empirical-identifiability risk identified in V5 is materially reduced by UTA1.6.

Within the registered canonical pair,

```text
Delta(p)=Phi+eta(2p-1),
```

two frequency treatments symmetric around one half identify both coordinates exactly:

```text
Phi=[Delta_+ + Delta_-]/2
eta=[Delta_+ - Delta_-]/(4q).
```

Repeating the design across ecological contexts reconstructs `Phi(E)` and `eta(E)`, so the environmental threshold predictions are experimentally estimable in principle.

## What is now directly testable

At each ecological context E:

```text
frequency treatment p_-=1/2-q
frequency treatment p_+=1/2+q
-> estimate Delta_-, Delta_+
-> recover Phi(E), eta(E)
```

Across contexts:

```text
Phi(E)=0              -> locate E_V
Phi(E)-eta(E)=0       -> locate E_I
local slopes          -> estimate Phi'(E_V), eta'(E_V)
predicted displacement
~ eta(E_V)/[Phi'(E_V)-eta'(E_V)].
```

Thus the theory specifies both the prediction and the minimal decomposition needed to test it.

## Main reviewer risk now expected

> Does real frequency dependence remain close enough to the registered linear canonical pair for Phi and eta to be meaningful summaries?

This is now the key model-adequacy question.

The response is falsifiable:

1. fit relative performance across more than two frequencies;
2. test curvature or asymmetry;
3. if linearity fails, do not force the canonical pair;
4. promote the richer empirical interaction surface and recompute invasion thresholds from that surface.

A failed canonical fit is therefore a model rejection, not permission to reinterpret Phi or eta.

## Remaining empirical difficulty

The harder biological problem is constructing or identifying matched S and D architecture states whose endpoint contrast is comparable across environments while preserving the intended architecture-cost definition.

That is already represented by G3-G5 and the operational K receipt.

## Strongest ecological contribution

~~~text
conflict vs architecture value
architecture value vs invasion
invasion/fixation vs long-run occupancy
~~~

and supplies a distinct measurement strategy for each layer.
