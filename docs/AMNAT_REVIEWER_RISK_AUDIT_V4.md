# SLK Am Nat reviewer-risk audit V4

## Current verdict

The main remaining conceptual risk after V3 was biological importance: reviewers could accept the critical-surface transport as mathematically coherent yet still ask what new ecological inference it enables.

The present ecological-deduction layer materially improves that point. The threshold atlas now yields two explicit comparative predictions and one diagnostic framework:

1. environmental displacement between architecture value and rare invasion;
2. non-monotonicity between conflict strength and differentiation across systems;
3. gate-specific interpretation of discordance between conflict, endpoint value, invasion, fixation, and occupancy.

The empirical claim ceiling is unchanged.

## New ecological prediction 1 — value and invasion cross at different environments

For the registered affine environmental slice,

~~~text
Phi(E)=a(E-E_V),  a>0,
~~~

the architecture-value crossing is

~~~text
E_V,
~~~

while rare D invasion occurs at

~~~text
E_I=E_V+eta/a
~~~

and resistance to reverse invasion at

~~~text
E_R=E_V-eta/a.
~~~

Thus

~~~text
E_I-E_V=eta/a.
~~~

This converts the abstract difference between Phi=0 and Phi=eta into a measurable ecological distance.

Interpretation:

~~~text
eta>0
-> rare invasion is delayed beyond positive architecture value
-> globally profitable differentiation can fail to establish from rarity

eta<0
-> rare invasion occurs before positive architecture value
-> negative-frequency feedback can admit D while intrinsic Phi<0
-> this is a coexistence route, not proof of endpoint superiority.
~~~

This is now the strongest ecological consequence of UTA1.

## New ecological prediction 2 — stronger conflict does not imply more differentiation

Under the quadratic bridge,

~~~text
Phi=sL-K.
~~~

Across systems,

~~~text
L_A>L_B
~~~

does not imply

~~~text
Phi_A>Phi_B
~~~

because recoverability and architecture cost can differ.

This gives a direct comparative warning: studies that rank populations or species by conflict magnitude alone should not expect a monotone ranking in integration/modularity unless R (or s) and K are also controlled.

## Diagnostic value of mismatch

The framework now makes disagreement between levels informative.

~~~text
strong L + Phi<0
-> persistent compromise / cost-recovery explanation

Phi>0 + negative local release gradient
-> small-step construction barrier

Phi>0 + failed rare invasion
-> coordination-like ecological feedback

Phi<0 + successful rare invasion
-> negative-frequency ecological rescue / coexistence route

reciprocal fixation ordering != occupancy ordering
under the registered process
-> process assumptions rejected
~~~

This is stronger than saying "more data are needed": each mismatch points to a specific next estimand.

## Main reviewer attack now expected

> The ecological-gradient result is elegant but still comes from a deliberately simple affine slice. How broadly should it be interpreted?

Required response:

1. the exact distance eta/a is claimed only for affine Phi(E) with locally constant eta;
2. for smooth non-affine systems it is explicitly a local first-order approximation;
3. the qualitative ordering is broader: positive eta pushes invasion beyond the value crossing, negative eta can pull invasion before it;
4. the manuscript does not claim universal environmental linearity;
5. the purpose is to generate a prospectively testable ecological prediction from the registered threshold geometry.

## Position relative to prior theory

SLK should not claim that ecological feedback, negative-frequency dependence, coordination, or modularity are themselves new. The contribution is that one architecture contrast is preserved across levels, which lets ecology move the invasion boundary relative to a separately measured architecture-value boundary.

The new ecological statement is therefore:

> ecology does not merely alter the strength of selection for differentiation; it can change which evolutionary criterion is crossed first.

## Journal positioning

Primary target remains **The American Naturalist, Major Article**.

The strongest framing is now:

> a theory predicting when functional conflict, architecture value, and realized differentiation should become discordant across ecological gradients, and which measurement resolves each discordance.

That is more biologically informative than the earlier "criteria must be re-tested" formulation while remaining inside the same theorem family.
