# SLKの生物学的接続：Cyananthusでは雄相の延長が雌機能の機会を奪う

**2026-11-15｜実植物の既刊3原著に基づく初回比較｜SLK PR #121 Draft 専用。**  
生物学的な主語は「雄機能と雌機能をひとつの花で時間分割すると、送粉者が不足したとき何が起きるか」。これは数式の新しいゲートではなく、**自然界の雄相→雌相の競合が実験によってどこまで検証されているか**の監査である。

## 要旨：時間的分業は葛藤の解消だけでなく、葛藤の再配置にもなる

キキョウ科 *Cyananthus delavayi* の両性花は雄性先熟で、雄相を経て雌相へ移る。通常は時間的な分離により自家花粉干渉を軽減できるが、送粉者が少なく花粉が取り去られなければ、**雄相が必要以上に長引き、有限の花寿命から雌相の時間を削る**。雌株はこの時間配分の拘束を受けない。雄相の花粉を早期に取り除く野外実験では、両性花の種子生産が雌株と同程度になったと原著は報告する。

つまり同じ形態的な両性花が、**花粉除去の状況によって雌性繁殖能力を回復し得る**。雌性遺伝子の「失われた後の再進化」ではなく、現存する機能の発現機会を取り戻す結果である。ここにSLKの「分業の利益は形態の本質的優劣だけでなく、生態的機会に依存する」が具体的に見える。以下は原著者による既知の成果であり、SLKの新規野外データではない。

## 三つの原著は同一種を異なる段階で実験している

| 原著 | 操作・観測単位 | 支持する事実 | 直接には支持しないこと |
|---|---|---|---|
| 2015 PLOS ONE, DOI [10.1371/journal.pone.0117149](https://doi.org/10.1371/journal.pone.0117149) | **20個体から125両性花を6処理に割付**。喉部毛状付属物除去、および花粉0／50／100%除去、訪花排除 | 花粉が除かれないと雄相が延び、雌相を圧縮。花粉無除去では**約3分の1で雌相が現れない**。**全体寿命も処理間で有意に異なる**（原著 F[5,118]=31.02, p<0.001） | 自然状態での雌雄分業の進化史、子孫の生涯適応度、雄の父性成功 |
| 2017 *Ecology and Evolution*, DOI [10.1002/ece3.3391](https://doi.org/10.1002/ece3.3391) | 雌株30、両性株30を選択し、**同一花**へのハナバチ・マルハナバチ・ハナアブの**単回訪花**後の柱頭花粉と30日後の種子を追跡（全147花） | 昆虫群で成熟種子数が異なり、ハナアブでは種子が少ない。公開原著Table 3で柱頭花粉数の条件付き効果は F=0.036, **p=0.850**、昆虫群の効果は F=15.231, **p<0.001** | 「花粉数が繁殖成果に一切影響しない」という等価性や、2021年の花粉除去操作の直接の媒介 |
| 2021 *Evolution* 75:278–293, DOI [10.1111/evo.14113](https://doi.org/10.1111/evo.14113) | 両性花の花粉を実験的に早く／少なく除去し、雄・雌相と母性種子を比較。**原著は5集団**で雌株の約**2倍の平均種子生産上の優位**を報告 | 花粉を早く除くと両性花は雌株と同程度の種子を作る。花粉除去不足は雄相延長・雌相短縮・種子減少をもたらす。**花全体の寿命には処理効果が検出されない** | 2021原著の未公開個体別効果量・CI、新規の遺伝子型侵入、雌株の歴史的起源をSLKが直接確かめたこと |

**独立性:** 2015・2017・2021は同じ植物系で著者群も重複している。異なる年・実験設計で同一の生物学的連鎖を強めるが、**3つの独立した性分業の進化起源ではない**。2021原著の本文と原データは公開要約・補足目録まで確認。介入を行った集団数が必ず5とまでは本文なしに断定せず、5は原著が報告した比較集団の範囲とする。

## 特に新しい生態学的解釈：時間で逃がした葛藤が、送粉不足で戻ってくる

両性花の機能的な時間配分は次の競合を持つ。

1. **雄機能の花粉輸出のための滞在時間**：花粉がまだ残ると雄相を維持しやすい。
2. **雌機能のための成熟時間**：雄相の後に始まるので、雄相の延長が雌相を圧迫する。
3. **花の有限の寿命**：2015年の6処理間では**全体寿命そのものも変わった**（F[5,118]=31.02, p<0.001）。一方、2021年原著要約では、異なる花粉除去操作による全体寿命の効果は検出されなかった。両実験で全体寿命が一定だったとは言えない。**それでも、どちらも雄相の延長が雌相を圧迫する**。
4. **子孫の成立**：2021原著の実験操作は雌相だけでなく、成熟種子まで効果を接続する。2017原著は、運ばれた花粉の数量と成熟種子数を単純に同一視できないことを同じ個々の花の単回訪花で示す。

**機能葛藤があるから固定的な構造分業が必ず進む、とは言えない。** このCyananthus系自体、花粉を早期に除けば既存の両性花の雌性繁殖が回復するという**環境依存の逃げ道**を持つ。先に存在する時間的な分業（雄性先熟）が、生態環境によって雌性機能を助けることも阻むこともある。

これはSLKでいう「共有構造のまま、生態条件が変わると各機能間の葛藤の実効的な意味が変わる」という考えの、実際の生物学的実例として重要である。ただし *Cyananthus* のDNA変異による別器官の獲得や、モデルの `Phi`, `g0`, `Delta_R` を同定していない。

## Wurmbeaとの比較：同じ『送粉者不在』を同じ効果にしない

2004年の西部 *Wurmbea dioica* subsp. *alba* における**送粉者の袋掛け排除**では、雌株と両性型の花の寿命が延びたのに対し、雄株の雄花では短くなり、雄株の両性花で効果は明瞭でなかった。これは集団内で開放・袋掛けを比較した実測の**性型×訪花アクセス応答**であり、花粉を意図的に除く *Cyananthus* とは異なる介入である。

| 生態的問い | Wurmbea 西部（2004） | Cyananthus 高山（2015–2021） |
|---|---|---|
| 現実に操作したもの | 送粉者のアクセス（袋掛け） | 花粉の除去量・タイミング、喉部毛状付属物 |
| 直接に測定した花の応答 | 性型により花寿命の延長・短縮が異なる | 雄相延長 ↔ 雌相短縮、全体寿命が一定のケース |
| 成熟種子までの介入接続 | 同一の袋掛け因果系列に対する完全な子孫適応度は未測定 | 2021年の花粉除去介入で母性種子の差を測定 |
| 不明な進化レベル | 西部と東部の分類・性分業の起源 | 性分業の遺伝子型侵入・歴史的成立 |

**自然史上の比較的な結論:** 送粉者との関係が変わると、**機能の順番と寿命のどちらが可塑的に変わるかさえ同じではない**。一方の機構を他方の種へ無条件に移植せず、また雄機能の花粉を除去した実験から雄性父性成功が上がる／下がるとは言わない。

## 実験的に識別できる次の予測

- *Cyananthus* で十分に花粉が除去される条件では、同じ両性花の**雌相の長さと母性種子生産が増え、雌株の追加的な母性利益は縮小する**。ただし遺伝子型生涯適応度（父性を含む）は未知。
- 花粉除去が遅い条件では、雄相と雌相の取り合いが顕在化し、雌株の相対的な母性利益は大きくなる。2021原著はこの条件依存性を支持。
- 訪花昆虫群と花粉数を分けると、種子形成の説明は花粉量だけでは完結しない可能性がある。2017原著では単回訪花による種子数の差は昆虫群で観測されたが、堆積花粉数の独立した説明効果は有意でなかった。
- 遺伝的な不可逆性・固定的な分業を結論づけるには、雌相への反応規準の遺伝的分化、自然交配下の父性／母性両方の適応度、長期の遺伝子型頻度変化が必要。**既刊3報だけでは未同定**。
