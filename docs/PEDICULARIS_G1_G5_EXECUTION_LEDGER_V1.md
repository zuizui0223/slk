## 1. Why this ledger exists

The Pedicularis programme now has an end-to-end prospective implementation from field qualification through G5. That does **not** mean the biological chain is closed.

This ledger keeps two statuses separate:

```text
DESIGN STATUS
    whether the protocol, freeze, layout, validator and adjudicator exist

BIOLOGICAL STATUS
    whether real independent data have produced the required receipt.
```

A registered script never upgrades an empirical claim by itself.


```text

```

The manuscript may promote a Pedicularis gate only after the corresponding real-data receipt is committed and its context matches every upstream promoted receipt.

## 6. Failure is informative

Every stage is fail-closed.

Examples:

```text
Qg method contamination
-> no G1 surface in that method/context.

G2 interval includes zero
-> measured conflict budget, no positive G2 promotion.

Y range unresolved
-> no structural-y LOW/HIGH route.

Y2 pollination cross-effect too large
-> no preferential-loading promotion.

D0 Q2 fails
-> no R/K point decomposition.

D0 qualifies but G3 R <= 0
-> second degree of freedom does not recover the registered conflict in that context.

L > 0 and R > 0 but Phi < 0
-> conflict is real and recoverable, but realized architecture is not worth its cost.
```

None of these failures may be rescued by reusing the failed confirmatory data under revised thresholds.
