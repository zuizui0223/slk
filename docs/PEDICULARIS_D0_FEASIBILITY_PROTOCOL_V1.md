# Pedicularis D0 feasibility protocol v1

Status: **PROSPECTIVE / QUALIFICATION ONLY / NO G4 CLAIM YET**.

## 1. Question

Can `Pedicularis rex` supply a biologically valid pre-cost differentiated comparator `D0` for SLK G3-G5?

The target is not to create an artificial treatment that simply improves fitness. The target is a comparator that supplies the **same focal y-mediated functional benefit** as the realized structural-y phenotype while avoiding, externalizing, or separately accounting for the focal plant's incremental structural debit.

The registered decomposition is:

```text
S  = shared / y-fixed structural state
D0 = matched y benefit supplied externally or pre-cost
D  = realized structural-y state

R = W_D0* - W_S*
K = W_D0* - W_D*
Phi = R-K.
```

## 2. Claim boundary: incremental-y cost versus whole-architecture cost

The cupulate bract already exists in contemporary `P. rex` across the focal worlds. An acute external reservoir cannot erase developmental costs already paid to construct that organ.

Therefore the first feasible G4 target is:

```text
K_incremental_y
= net reproductive-fitness debit of expressing the registered high-retention
  structural-y state, relative to a benefit-matched pre-cost comparator,
  conditional on the background cupulate-bract architecture already existing.
```

This is a valid comparison-specific SLK `K` only if the S/D architecture contrast is prospectively defined as the **incremental structural-y difference**.

It is not licensed to mean:

```text
cost of evolving the cupulate bract from absence;
whole developmental cost of the bract organ;
historical origin cost of modularization.
```

A whole-architecture `K` requires a developmental/genetic/natural comparison in which the architecture itself is absent or its construction cost is otherwise identified.

## 3. Preferred D0 implementation

Primary candidate:

```text
reversible externalized water-retention support
(e.g. standardized sleeve / micro-reservoir)
```

applied to a prospectively defined low-retention or y-fixed structural state.

The apparatus must reproduce the target high-y water-retention/protection function without changing the plant's own structural-y phenotype.

The exact device is not promoted by name. It is promoted only after passing D0-Q1 to D0-Q6.

## 4. Qualification groups

Use a calibration set that is excluded from confirmatory G3-G5 estimation.

At minimum include:

```text
S_cal      registered low-y / y-fixed comparison state
SHAM_cal   S_cal + inert apparatus matching handling/material burden
D0_cal     S_cal + externalized retention support
D_cal      realized high-retention structural-y state
```

Where feasible, block these treatments within plant, genotype, site, flowering date, and initial flower condition. If the device cannot be randomized within plant without carryover, randomize at plant level and preserve plant as the inferential cluster.

Do not choose `S_cal` or `D_cal` after seeing reproductive outcomes. Their y ranges must be frozen from structural-y qualification data.

## 5. Stage D0-0 — geometry and coordinate preservation

Before any fitness endpoint is used, verify that adding the external support does not materially alter the registered x/z axis.

Measure at minimum:

```text
realized exsertion z
corolla opening width
stigma position
flower orientation
pollinator entry geometry
bract position / compression
mechanical damage
```

Primary qualification:

```text
D0-Q1 z preservation = PASS
```

only if all predeclared geometry changes remain within independently frozen equivalence tolerances.

A treatment that changes exsertion or pollinator entry geometry is not a valid D0 even if it improves seed survival.

## 6. Stage D0-1 — match the focal y benefit

The D0 device must reproduce the focal functional consequence of natural structural y.

Preferred directly measured y variables:

```text
maximum retained water volume
standardized water depth
retention duration / half-life
leakage rate
fraction of vulnerable ovary/corolla-base region protected during the attack window
```

Compare `D0_cal` with `D_cal`, not merely with S.

Primary qualification:

```text
D0-Q2 functional-benefit matching = PASS
```

requires D0 and D to fall within a prospectively frozen equivalence region for the target y-performance profile.

A single matching mean with strongly different time courses is insufficient if predator exposure depends on duration.

## 7. Stage D0-2 — pollination-facing neutrality

Externalized retention must not create a second attraction/handling effect that natural structural y does not have.

Measure, as feasible:

```text
legitimate visit probability / rate
handling time
entry angle or contact geometry
pollen receipt
stigma contact
initial seed set after standardized exposure
```

Compare:

```text
D0_cal versus SHAM_cal
D0_cal versus D_cal
```

Use equivalence or bounded-effect criteria, not `P > 0.05` as evidence of no effect.

Primary qualification:

```text
D0-Q3 pollination-facing equivalence = PASS.
```

## 8. Stage D0-3 — antagonist-channel fidelity

The device must protect through the intended retention/water-defence route rather than by physically excluding the antagonist.

The strongest design separates:

```text
water/retention present versus absent
x device physical structure present versus sham
x antagonist access assay
```

Required evidence should distinguish at least:

```text
egg/oviposition access
initial attack
subsequent seed predation / viable-seed loss
```

A sleeve that simply blocks oviposition mechanically fails D0-Q4 even if its final fitness matches D.

Primary qualification:

```text
D0-Q4 antagonist-channel fidelity = PASS.
```

## 9. Stage D0-4 — apparatus burden

`D0` is not cost-free by assumption. Estimate the burden of the device using `SHAM_cal` and, where needed, a second material-only control.

Potential burden channels include:

```text
added mass / bending
shading
microclimate
waterlogging beyond the natural y range
mechanical abrasion
changed visitation
handling damage
fruit development interference
```

On the registered reproductive scale estimate or bound:

```text
B_device = W(S_cal) - W(SHAM_cal)
```

with sign convention declared prospectively.

D0-Q5 passes only if this burden can be corrected on the same scale or bounded tightly enough that the intended sign/classification of K cannot be reversed by plausible device burden.

If not, retain only a bound on K.

## 10. Stage D0-5 — common time horizon

S, D0, and D must be evaluated over the same biological interval. The preferred horizon is:

```text
focal flower at treatment assignment
-> mature viable undamaged seeds
```

If longer-term maternal costs are scientifically relevant but not observed within this horizon, they belong in an explicit excluded-channel ledger and the claim must remain reproductive-episode-specific.

Primary qualification:

```text
D0-Q6 common horizon = PASS.
```

## 11. Two admissible D0 routes

### Route A — same-block internal decomposition

Use one registered S/D0/D experiment to estimate all three optimized worlds.

Advantages:

```text
shared context
high covariance efficiency
minimal environmental mismatch
```

Limitation:

```text
Phi_direct = Phi_decomp
```

is then an algebraic identity, not independent empirical validation.

### Route B — independent/partially independent decomposition

Use a separate preregistered block for R/K decomposition while direct S:D Phi is estimated in the matched worldline block.

Requirements:

```text
same target population-season or registered bridge
same fitness scale and horizon
same frozen S and D definitions
same y target definition
independent randomization / estimation block declared before outcome inspection
```

Only Route B can support `STRUCTURAL_G1_G5_CLOSED_CONCORDANT` in the current SLK adjudicator.

## 12. Pre-confirmatory freeze

Before opening confirmatory G3-G5 outcomes, freeze:

```text
structural-y low/high or continuous comparison definition
D0 device specification
sham specification
all D0-Q1 geometry equivalence margins
D0-Q2 y-performance equivalence margins
D0-Q3 pollination cross-effect margins
D0-Q4 channel-fidelity criteria
D0-Q5 acceptable burden/bounding rule
D0-Q6 horizon
optimization ranges for S, D0, D
cluster/bootstrap unit
primary model and uncertainty procedure
same-block versus independent-block route
bridge-concordance tolerance if Route B
```

Calibration flowers/plants used to choose these thresholds are excluded from the confirmatory architecture-value analysis.

## 13. Feasibility outcomes

```text
D0_FULLY_QUALIFIED
    Q1-Q6 pass; point-identification route may proceed.

D0_QUALIFIED_WITH_BOUNDED_BURDEN
    Q1-Q4 and Q6 pass; Q5 supports only a bounded apparatus correction;
    K and Phi inherit bounds.

D0_FUNCTION_MATCH_ONLY
    retention/protection is reproduced but one of geometry, pollination, channel fidelity,
    or burden gates fails; D0 cannot identify K.

D0_NOT_QUALIFIED
    focal benefit itself cannot be matched or structural y is not validated.
```

A failed D0 pilot is scientifically useful. It says the current system can test direct architecture value more strongly than it can decompose that value into R and K.

## 14. Immediate sampling logic

The first field objective is not a large confirmatory factorial. It is a small, explicitly non-confirmatory qualification programme capable of estimating:

```text
repeatability and range of structural y
D0-D retention equivalence
D0-sham geometry effects
D0-sham pollination-facing effects
D0 channel fidelity
sham burden variance
```

Those estimates determine whether a full S/D0/D experiment is identifiable and provide the variance inputs needed for power/precision design. Historical sample sizes may be used only as feasibility anchors, not as the final power calculation.

## 15. Current conclusion

For `Pedicularis rex`, the strongest presently plausible route is:

```text
G1-G2 causal conflict
-> structural-y qualification
-> D0 qualification for incremental high-retention architecture
-> R and K_incremental_y
-> Phi for the registered S:D structural-y comparison.
```

This route can close SLK G1-G5 without pretending that a contemporary sleeve experiment measures the historical total cost of originating the cupulate bract.
