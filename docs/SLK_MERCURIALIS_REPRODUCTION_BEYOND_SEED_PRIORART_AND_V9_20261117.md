# SLK：多機能性は花粉不足による次世代の損失を緩和するか？—既刊先行研究と真正個票再解析

**2026-11-17／生物学的な実証限界／実証Draft PR #121限定。** 最初の問いは「花粉を受ける／花粉を出す」ではなく、「同じ雌花から次世代に到達した個体がどれだけ残るか」。既刊論文に知られている生理的・繁殖的な機構と、今回新たに再解析した個体別データの結果を明確に分離する。

## 重要な先行研究：花粉距離×子の品質はSLKの新発見ではない

Labouche, Richards & Pannell, *Journal of Ecology* **105:197–208 (2017)**、[DOI 10.1111/1365-2745.12659](https://doi.org/10.1111/1365-2745.12659)。**online first 2016-09-04**。2012年実施の実験は、欧州25**雌雄異株**集団からの種子を用い、**中心に雄12株、周囲0.2～25mの雌442株**を置いた。最寄りの雄への距離を操作し、柱頭花粉を**実際に計数**、母性種子数／種子重量、播種後の発芽・子の生育／繁殖配分を追った。

原著がすでに報告した主成果：

- 近距離0.2〜0.5mで柱頭花粉粒数**23.9±4.1**、遠方20〜25mで**2.5±0.4**。測定値は平均±SE。花粉量と距離の関係を**直接確認**している。
- 最も遠い25mでは、0.2mに対して**約77%少ない種子**を母株が生産。同時に遠方の母株は**より大きい種子**を作り、近距離と遠方の平均種子質量は**2.35±0.12mg vs 2.81±0.13mg**。
- 同じ種子質量なら、近距離の母株から得た子の方が発芽しやすい傾向が原著で認められたが、花粉競争による遺伝的子の品質と、母株の資源・発生の寄与を完全には分離できない。平均種子サイズが増えることによる補償は**近距離の種子数の優位を覆さなかった**。原著の**母体を通じた相対適応度2.73倍**は、子の雄性適応度を花粉配分と交配集団平均から推定するなどの**仮定を置いた試算**であり、野外父性による全生涯適応度の直接計測ではない。
- 2016オンライン／2017巻号の本研究は、**密度・距離・花粉量・子の品質・性型別配分の先行理論も既に含む**。SLKは「子の品質まで測れば分業が説明できる」という機構の初出を主張しない。

2017-08-16公開[Dryad 10.5061/dryad.55186](https://doi.org/10.5061/dryad.55186)の**原個票2ファイル**は公開目録・列定義が検証できたが、2026-11-17時点のGitHub Actions環境での公式APIの直接ダウンロードは**401 Unauthorized**、ウェブ用streamは**403 Forbidden**。利用者の認証が必要なため**元の2017 Dryad個票の再フィット・新しい数値算出はしていない**。アクセス失敗とsource metadataは[workflow run #43897017616](https://github.com/zuizui0223/slk/actions/runs/43897017616)のartifactsに保全。

## 2024の別系統・別実験で新規に再計算したこと

Nguyen, Martignier & Pannell (2024), *American Journal of Botany* 111:e16429、[DOI 10.1002/ajb2.16429](https://doi.org/10.1002/ajb2.16429)、原データ[Figshare 10.6084/m9.figshare.26521189.v1](https://doi.org/10.6084/m9.figshare.26521189.v1)、完全なZIP MD5 **365ab41f1d6192344a3b3fec87654e49**。これは**六倍体**三性型のMotril付近の系、2017年の雌雄異株研究と同じ遺伝背景ではない。中心0m／0.5m／1.5m、**雄も雌も両性型も配置し、環には両性型が花粉を供給できる**。実際の柱頭花粉付着量、父性遺伝型をこの実験で測定してはいない。原著は非結実割合と種子バイオマスを報告したが、原CSVにはさらに播種後の発芽と子の形態があった。

追加した母株**71株**の二項個体データ解析：**播種4826粒、発芽2856個体**（72 F/H株のうちH1株は種子ゼロで発芽率が未定義）。母株内の発芽数を独立した処理反復として扱わず、ブロック×性型×距離の**実際の植物セルを保持した母株単位1200ブートストラップ**で区間を計算した。

| 分析 | 中央の雄群から距離が1m増す場合の発芽オッズ比 | 母株条件付きbootstrap 95%区間 |
|---|---:|---:|
| 性型・ブロックを含む全体の grouped-binomial logit | **0.7757** | **0.6784〜0.8879** |
| 中心を除いた0.5m・1.5mの雌／両性型のみ | **0.6220** | 今回は未算出 |
| ブロック1除外 | **0.8345** | 今回は未算出 |
| ブロック2除外 | **0.7544** | 今回は未算出 |
| ブロック3除外 | **0.7399** | 今回は未算出 |
| 観察上の異常・注意フラグを除外 | **0.7915** | 今回は未算出 |

**Pearson残差分散比 ≈3.085** は、独立な個々の種子を同質な単純二項試行と仮定した誤差が過小になり得る警告。上記は**母株単位条件付き区間**であって、自然地域一般／3区画のブロック間反復の完全な信頼区間でも、無作為な地理・生態要因の因果調整でもない。複数の結果を探索しているため有意確率の多重性を考慮した確認的仮説の支持ではない。

### 分業した雌は、両性機能株より「発芽の距離コスト」が大きいか

公表原CSVの母株から播種した子の**プール発芽率**：

| 性型 | 中心0m | 0.5m | 1.5m |
|---|---:|---:|---:|
| 雌 F | 543/882 = **61.6%** | 537/777 = **69.1%** | 470/927 = **50.7%** |
| 両性型 H | 491/825 = **59.5%** | 490/834 = **58.8%** | 325/581 = **55.9%** |

雄群から遠い方で**Fの低下が大きく見える**。しかし、全体の交互作用モデルでは、Hでの距離log-odds勾配**−0.0938**、F追加勾配**−0.2802**（母株bootstrap95% **−0.5727〜+0.0041**）で、**ゼロをわずかに含む**。従って**両性型の距離耐性の方が高いことは確証されない**。元の2024原著が分析した「非結実割合の性型×距離」もp=0.80で検出されておらず、今回の発芽結果をその実験の再証明や「性型で進化的に対照した実験」とは呼べない。

**事後の草丈・種子質量による既存V8の感度分析では距離–発芽の負の関連は残った**（固定ブロックOLS −0.0610/m、草丈追加−0.0586、草丈+平均種子質量−0.0592）。しかし草丈は距離と連動し、遠方の環では株間隔も大きいため、**花粉量の単独操作になっていない**。また播種割合は各株で異なり、Fの1.5mで作られた種子の平均**約94%**が調査されたのに対して、Fの0.5mでは**約76%**が播種された。抽出が無作為である保証は原CSVだけでは分からない。

### 既刊2017対2024：同じ「距離」でも全く同じ操作ではない

| | Labouche et al., J Ecol 2017 | Nguyen et al., AJB 2024・今回の新規再解析 |
|---|---|---|
| 自然生殖系 | 欧州25雌雄異株集団に由来 | Iberiaの六倍体三性型集団 |
| 花粉源 | 中央の雄12株 | 中央の雄＋同じ環の両性型も花粉源 |
| 距離 | **0.2～25m** | **中心、0.5、1.5m** |
| 実測された花粉量 | 柱頭上に直接計数 | **未計数**、未結実花を代理指標にした |
| offspringの評価 | 種子別サイズ、個別発芽、子の生育・繁殖配分 | 母株別の播種発芽数（新再解析）と子の性型 |
| 新しい比較でまだ不明なこと | 雌雄異株集団の結果を六倍体へ因果移植できるか | 受粉機構、父性、成熟後の子の生存、分業の遺伝的侵入 |

ここでの**強い生物学的主張は限定的**：「外部花粉供給への依存は、母性種子数だけでなく発芽まで波及し得る。ただし、生殖系によるその影響の緩衝は未確定」。2017年原著が既に示した種子数・品質のトレードオフの**一般化、初発見、新しい因果メカニズム、真のSLK希少侵入**を主張しない。

### SLKのために今後必要な1つの実験

**同じ六倍体遺伝背景と同じ雌花数／植物サイズのF・Hを同数配置し、花粉供給を独立に操作**する。交配相手を「雄あり・なし」「近・遠」「自家受粉可・不可」と交差させ、柱頭花粉・種子数・遺伝的父性／自殖・種子質量・発芽・実生生存を同一母株で追う。もしHだけが雄不在下でも父性・母性の経路を確保できて、発芽後の次世代数でFを上回るなら、**多機能性の生態的保持機構**に接近できる。逆にHとFの最終的な次世代成果がほぼ同じなら、多機能性が維持される理由として**資源費用や遺伝的構造**の方を問う必要がある。
