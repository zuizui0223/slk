# SLK：両性型の子の割合が増えても総子数は増えるのか

2026-11-17、既刊2024年六倍体 *Mercurialis annua* 個票の**探索的二次解析**。Draft PR #121のみ。原著 Nguyen, Martignier & Pannell (2024), AJB DOI [10.1002/ajb2.16429](https://doi.org/10.1002/ajb2.16429)。真正元データ [Figshare DOI 10.6084/m9.figshare.26521189.v1](https://doi.org/10.6084/m9.figshare.26521189.v1) ZIPのMD5 `365ab41f1d6192344a3b3fec87654e49`を検証済み。

## 割合と次世代の個体数を混同しない

既存の[母株→子の性型の解析V10](SLK_MERCURIALIS_2024_DENSITY_OFFSPRING_MORPH_V10_20261117.md)では、2024年元の72 F/H母株のうち71株が播種・発芽試験に参加し、播種4826、発芽2856、性型判別2749、未判定107。H母株からの性型判別子のうち、雄+雄性不稔雄型は中心0mで**40.2%**、1.5mで**13.5%**、両性型子は**40.2%→69.3%**だった。F母株では雄型子の割合42.8%→39.5%で変化が小さかった。母株性型×距離の雄型子ロジット交互作用は+0.8119、条件付き母株bootstrap95%区間+0.4850〜+1.1561。ただし**母株のCMS・核回復遺伝子、父性、真の自殖は未同定**。

子の性型割合だけでは、母株の繁殖保証の利益は判断できない。そこで、2024年原CSVの同じ母株について次を計算：

`期待される各性型発芽子／元の雌花 = (成熟種子数／雌花数) × (発芽実験で観察した該当性型子数／播種数)`。

ここには**播種された種子が母株の全収穫種子を代表する**という仮定が必要。野外実生定着、子の生涯適応度、実際のY・CMS遺伝子型の伝達、父性率を直接測った値ではない。同じ母株の5カテゴリー期待値を足せば、発芽期待値全体と一致することを検証。

### 原CSVの品質問題を排除

**H母株3株**で播種数が記録総種子数を1〜2粒上回った（中心0mに2株、1.5mに1株）。**これらを全収穫種子へ外挿せず、期待個体数の解析から除外**する一方、実測した性型割合（V10）では残す。種子ゼロのH母株1株は期待個体数ゼロ、発芽型割合には含めない。元のV10の割合と下表は異なる分析標本数。

| H母株の雌花1個あたり期待発芽子 | 中央0m（10株） | 1.5m（8株） |
|---|---:|---:|
| 両性型の子 | **0.366** | **0.489** |
| 雄型＋雄性不稔雄型 | **0.334** | **0.113** |
| 雌型の子 | 0.171 | 0.131 |
| **全性型の発芽子** | **0.916** | **0.785** |

**解釈：** H子の構成比が急上昇しても、次世代の**総数**は増えていなかった。H子の雌花当たり期待値は上昇傾向だが、固定ブロックOLSの距離勾配**+0.0831/m**、セル内母株1500bootstrap95%区間**−0.0022〜+0.1641**とゼロを含むので、**H子の絶対数の増加を確認的に証明したわけではない**。F母株との距離交互作用は**−0.0896**（bootstrap区間**−0.1761〜−0.0045**）。雄型子単独（雄性不稔雄型は除く）のH距離勾配は**−0.1656/m**（区間**−0.2109〜−0.1260**）。

注意：H1.5mは母株**元9株、外挿使用8株**。3ブロックと小セルでの多指標探索で、地域一般の信頼区間・構造分業の適応度差の因果効果ではない。中心雄群からの距離は実際の最寄り花粉源への距離ではなく、環上のH株も花粉を放出する。草丈・資源状態・母株遺伝背景・母株ごとの播種サンプル抽出の偏りが残る。

### 生物学として残った核心

両性型は外部の雄が少ないとき**両性型の子が相対的に多くなる**場合がある。しかし、そこから**子の生産総数の増大や分業への適応上の勝利を直接導くことはできない**。過去のPannell (1997)（DOI 10.1038/sj.hdy.6881080）は雄不在で両性型子のみの成立を、Eppley & Pannell (2007)（DOI 10.1111/j.1558-5646.2007.00195.x） は密度・自殖・雄の父性競争を別実験で既に示している。SLK独自の作業は**2024年三性型混在の真正個体別データで、性型割合と総子数を段階ごとに切り分け、母株型×空間条件の違いとその限界を監査したこと**。進化による性型変遷や`Phi/g0/Delta_R`を新たに実測したことではない。
