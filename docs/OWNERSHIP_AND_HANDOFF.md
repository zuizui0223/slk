# SLK Ownership and Handoff

## Purpose

SLK is the canonical owner of the integrated cross-repository flagship argument. The sister repositories retain ownership of their independent residual programmes. This document prevents duplicated canonical claims and future scope drift.

## Canonical flagship ownership

SLK owns the following integrated statements:

```text
SCH      -> valid conflict budget L
BALANCE -> L>0, Phi<0 identifies persistent compromise
BITA    -> recoverable architecture value R and general margin Phi=R-K
           with R=sL retained as the registered quadratic partial-release corollary
PAYOFF  -> architecture value is distinct from accessibility, invasion, fixation, occupancy
```

SLK may cite source derivations and implementations, but the integrated manuscript is canonical here.

## Anti-duplication rule

A result is not published twice merely by changing notation or biological framing. If SLK uses a theorem as a central result, a sister paper may:

- provide the full proof or stronger generalization;
- develop a distinct estimand;
- provide an empirical identification method;
- extend the result to a new mathematical class.

It should not present the identical claim as a second primary novelty.
