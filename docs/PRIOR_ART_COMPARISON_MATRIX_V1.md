# SLK prior-art comparison matrix V1

## Purpose

This matrix tests whether the SLK flagship is merely a relabeling of established theories of modularity, specialization, adaptive accessibility, finite-population games, or weak-mutation dynamics.

The comparison criterion is not whether antecedents contain one of the same ingredients. It is whether they contain the full SLK handoff object:

```text
identified shared-coordinate conflict L
-> recoverable benefit R
-> architecture margin Phi=R-K
-> local accessibility
-> rare invasion
-> fixation criteria
-> weak-mutation occupancy
```

with explicit constructive split regimes, a declared process-level invariant, and an empirical claim-ceiling ladder.

## Strongest novelty candidate

After comparison with the closest antecedents, the strongest defensible novelty is not any individual arrow. It is the **registered handoff structure across arrows**:

```text
identified conflict receipt
-> recoverable architecture value
-> net architecture margin
-> local mutation/path accessibility
-> rare-frequency population success
-> finite-population fixation criterion
-> weak-mutation long-run occupancy
```

The flagship adds three architecture-specific pieces to this synthesis:

1. a common upstream `L -> R -> Phi` bookkeeping that prevents multifunctionality, conflict, recoverable benefit, and net architecture advantage from being collapsed;
2. constructive parameter witnesses for the exact transitions where one criterion fails to imply the next;
3. an exact process-level re-alignment in which reciprocal fixation ordering and symmetric rare-mutation monomorphic occupancy ordering coincide, plus an empirical G1-G9 claim ladder that states what must be measured before each biological interpretation is licensed.

## Novelty danger zones

The following framings should be treated as already occupied prior art:

```text
conflict favors modularity
specialization can evolve when benefits exceed costs
modularity improves evolvability
fitter endpoints may be mutationally inaccessible
invasion and fixation differ in finite populations
weak-mutation evolutionary games have long-run stochastic state distributions
```

The following framing remains the candidate SLK contribution:

> A measurable functional-conflict receipt can be transported through a registered sequence of architecture-value, accessibility, invasion, fixation, and occupancy estimands without silently treating them as equivalent; the resulting architecture-specific hierarchy contains explicit split regimes, an exact re-alignment under a declared stochastic process, and a gate-by-gate empirical claim ceiling.

## Submission implication

A skeptical reviewer can reasonably say that every component theory has antecedents. The manuscript is publishable only if the integration produces useful deductions that are not obvious from juxtaposition alone. The current strongest deductions are:

- the explicit architecture accessibility gap after positive endpoint value;
- the constructive witness table locating each failed implication;
- the fixation-occupancy invariant under the registered process;
- the measurement ladder that makes claim strength cumulative and auditable.

If these are treated as examples of a general transport discipline rather than as disconnected mini-results, the novelty case is materially stronger.
