# SLK empirical G1-G9 source-system ledger v1

Status: **source-adjudicated mapping of existing empirical systems to the SLK measurement ladder**.

This ledger answers one narrow question:

> Which empirical systems already measure the estimands required by SLK G1-G9, and which source repositories therefore contribute direct biological evidence to the flagship rather than only theory, readiness, reality anchors, or generic analogues?

It is deliberately conservative. A biological example is not promoted merely because it resembles a later SLK stage.

## 2. Status vocabulary

The gate cells use five non-equivalent labels.

```text
DIRECT_PASS
    The source identifies the gate estimand under the SLK-compatible biological comparison.

PARTIAL_SUPPORT
    The source measures a necessary component, but one or more required causal, scale,
    architecture, or process conditions remain open.

ANALOGUE_ONLY
    The source directly measures the generic downstream process, but not for an independently
    qualified SLK shared-versus-differentiated architecture pair.

REALITY_ONLY
    The source demonstrates that a biological architecture/state/transition represented by the
    theory occurs, without estimating the gate estimand.

NOT_IDENTIFIED
    The gate estimand is not identified by the source.
```

`ANALOGUE_ONLY` is especially important for PAYOFF. A real frequency-dependent game can validate a population-process layer without identifying SLK architecture-specific invasion.

## 3. Gate definitions used by this ledger

| Gate | SLK estimand | Minimal direct-evidence requirement |
|---|---|---|
| G1 | shared-axis causal conflict | opposing function-specific effects isolated on one shared coordinate |
| G2 | conflict load `L` | valid conflict receipt on one common fitness scale |
| G3 | recoverable loss `s` or `R` | matched shared-versus-differentiated comparison |
| G4 | architecture cost `K` | operational architecture cost on the same fitness scale and horizon |
| G5 | `Phi=R-K` | compatible G2-G4 measurements supporting the architecture-value sign |
| G6 | local accessibility | explicit mutation/release neighborhood or stepwise path from the current state |
| G7 | invasion / feedback | rare-frequency or frequency-dependent relative performance for the qualified architecture pair |
| G8 | fixation | explicit stochastic finite-population process linked to the qualified pair |
| G9 | stationary occupancy | mutation graph/kernel plus the declared weak-mutation process |

## 5. Repository-level flagship contribution

### SCH — **current primary biological contributor to SLK entry evidence**

SCH contributes the strongest empirical support at the left edge of the SLK hierarchy: real shared-trait multifunctionality, opposing-selection cases, geographic functional-weight variation, and candidate causal designs. However, SCH itself states that the biological fitness-scale `L` receipt is not yet executed. Therefore SCH currently supports G1 most strongly but does not directly close G2.

Flagship role:

```text
biological conflict reality / G1 support
+ causal-entry design
- no completed biological L receipt
```

### BALANCE — **direct middle-world machinery, empirical worldline still open**

BALANCE supplies the direct `W_S*` versus `W_D*` middle-world formulation and matched-worldline machinery. Its current focal `Pedicularis` direct worldline biology is explicitly not yet executed. Thus BALANCE is essential to the flagship logic but currently contributes no completed new biological G2-G5 gate beyond imported upstream reality anchors.

Flagship role:

```text
middle-world identification method
+ candidate same-system bridge
- direct biological worldline not yet closed
```

### BITA — **architecture-state reality + post-differentiation mechanism evidence**

BITA contributes two biologically important but non-substitutable assets:

1. natural architecture-state anchors such as cichlid partial differentiation and `Peucedanum` functional differentiation;
2. the 56-route / 25-cluster / 17-system fragmented mechanism-identification frontier.

Neither asset directly estimates `R`, `K`, or `Phi`. Therefore BITA materially strengthens biological plausibility and the mechanism layer, but it does not yet close SLK G3-G5.

Flagship role:

```text
architecture-state reality
+ mechanism-identification depth
- no direct R/K/Phi receipt
```

### PAYOFF — **downstream process stress tests without architecture-specific closure**

PAYOFF contains the strongest empirical analogues for frequency feedback and reciprocal game logic, including manipulated multi-frequency plant data and microbial near-Lane-P systems. But its evidence-lane firewall correctly keeps generic game validation separate from architecture mapping, and current Lane P remains unclosed. Finite-population and recurrent-mutation empirical tests are also still unexecuted.

Flagship role:

```text
generic G7 process transportability
+ architecture-frequency measurement design
- no qualified architecture-specific G7
- no biological G8/G9
```

## 6. What the ledger changes

The current empirical shape of SLK is therefore not

```text
G1 -> G2 -> G3 -> ... -> G9
all already measured in one or several systems.
```

It is instead

```text
G1    substantial biological support, mostly partial / observational
G2    estimator and design ready; biological L receipt open
G3    architecture-state reality exists; direct R receipt open
G4    operational definition ready; direct K receipt open
G5    no biological Phi classification from independently identified R and K
G6    theory / intervention-path design only
G7    multiple generic empirical analogues; architecture-specific mapping open
G8    theory / design only
G9    theory / design only
```

This is a strength if stated explicitly: SLK is an estimand-transport theory with a transparent empirical ladder, not a retrospective relabelling of heterogeneous published systems as end-to-end validation.

## 7. Flagship contribution ranking

For **current evidence already in hand**, rank source contributions as follows.

1. **SCH / Dalechampia + Pedicularis** — strongest direct biological support for the entry conflict problem.
2. **BITA / Peucedanum + cichlid + 17-system frontier** — strongest evidence that differentiated states and post-differentiation mechanism problems are biologically real.
3. **PAYOFF / Dactylorhiza + Primula + Arabidopsis + microbial systems** — strongest downstream process analogues, but architecture-specific promotion is blocked.
4. **BALANCE** — scientifically central for G2-G5 identification, but current biological contribution is prospective rather than completed.

For **next experiment value**, the order differs:

1. **Pedicularis same-context chain** — highest leverage because one qualified population/season could close G1 -> G2 and feed the matched BALANCE/BITA architecture comparison.
2. **Dalechampia conflict-qualified causal surface** — strongest alternative route to a true G1/G2 biological receipt.
3. **A matched architecture-specific frequency system in PAYOFF** — necessary before generic G7 analogues can become direct SLK population evidence.

## 8. Promotion firewall

No entry in this ledger licenses any of the following shortcuts:

```text
observed stabilizing selection           != identified L
partial differentiation exists           != identified R
endpoint shared-vs-differentiated gap    != identified K
R-like state improvement                  != Phi without K
frequency-dependent morph fitness         != SLK G7 without architecture mapping
reciprocal fitness ordering               != fixation
fixation ordering                          != occupancy without mutation kernel
```

A future update may promote a system only when the new source directly supplies the missing estimand under the gate definition frozen above.
