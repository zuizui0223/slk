# SLK｜戻せる機能と、戻したあとに生じる新しい葛藤：*Mercurialis* G0–G8の実証境界

**2026-11-15／生物学を主語にした原著連結／実証Draft PR #121のみ。**
重要な問いは「分業が崩れ、両性機能が再び使われるようになったあと、その多機能状態はいつ有利で、いつ再び不利になり得るのか」。**実験で直接証明されたのは「機能の再発現と父性寄与」までで、雌雄異株へ戻る進化はまだ観測されていない。** 本ノートは既刊の同じ実験進化系列の世代を整理する。原著独自の新しい個体データや新しい適応度モデルを作成したという意味ではない。

## 1. 戻る機能は本物：ただし再分化まで追跡してはいない

Cossard et al. (2021) [Current Biology, DOI 10.1016/j.cub.2020.12.028](https://doi.org/10.1016/j.cub.2020.12.028) の二倍体 *Mercurialis annua* で、XY雄を除いた3つのXX子孫集団を雄あり3対照と比較した。雄がいないG0で雌の雄花量は2.33倍（急性応答）、選択下のG1では8.77倍、G4では**23.3倍**の雄花量（**同世代の対照雌との比較**）。雄花陽性の雌はG0 5.48%からG4 69.3%へ。G0からG4までの子孫共通庭園比較は急性環境応答だけで説明しづらいが、遺伝子突然変異と継承性のある他の要因をこの資料だけで厳密に分離しない。

G5で雄を復帰させた6交配アレイ（各50 XX雌＋50 XY雄）では、選択下のXX雌の子供の雄割合が43.6%。XY雄由来なら雄50%という原著の遺伝仮定から、XX由来花粉が父親の子の割合を **2×(0.5−0.436)=12.8%** と**間接推定**した。これは実際の再獲得雄機能が競合環境でも次世代に寄与した証拠。ただし一粒ずつDNAで父親を特定した値ではなく、XX自殖とXX個体間交配を区別しない。雄再導入後に再度雌雄異株へ進化・固定したという結果はない。

G1/G4の**8 SSRによる集団別自殖率（RMES）**は、雄なし集団3つの掲載推定平均で**G1 0.1913／G4 0.1223**、差−0.069、原著p=.10で非有意。雄花が増えれば自殖率が単調に増すという結論は出ない。

## 2. G8で初めて測れたのは「再発現した雄機能の遺伝的父性」と「自殖との衝突」

Chen & Pannell (2025) [New Phytologist, DOI 10.1111/nph.70356](https://doi.org/10.1111/nph.70356) は同じXXのみの実験進化**系列から8世代後の種子**を用い、3つの共通庭園（各61株）の雄花・雌花、成熟種子、9 SSRによる父性を調べた。**2021論文のG4個体を再測定した縦断追跡ではない**。

- **形質を測定できた180株**で、雄花と雌花への配分は負の関連（原著p<.001）。両性機能の資源配分には実際のトレードオフがある。
- **181親個体、958種子**からDNA抽出。948種子の遺伝子型が利用可能で、**915種子の父親を割り当てた**（Cervus、80%の緩い信頼閾値）。遺伝子型判定可能種子に対する父性割当率 **915/948=96.52%** と、全生産種子約13,800粒に対する父性標本 **約6.6%** は別の分母。「全種子の96.5%について父性を測定した」ではない。
- **172株の個体別自殖率の平均29.6%**。雄配分が大きいほどその個体の自殖率が高い（原著p<.001）。これは「915種子中の自殖粒率29.6%」とは限らない。またG1/G4の集団別RMES（8 SSR）とG8の個体別父性比率（9 SSR）は直接の増減系列として結べない。
- 自殖の近交弱勢 **δは当該二倍体集団では実測されていない**。原著は **δ=0 または δ=1** という両極の仮定で、実際の成熟種子数と父性推定を用いて雌・雄・総繁殖成功を計算した。δ=1の「総繁殖成功」は自殖子孫に完全な適応度損失を仮定した推定値であり、野外の生存子孫数を観察した値ではない。

原著Table 1にある**総相対適応度～雄配分の二次係数**（括弧内SE、同じ個体から2つのδシナリオを作成）：

| 植物サイズ | δ=0 | δ=1 | δ=1で「中間型が不利」という正の二次曲率 |
|---|---:|---:|---|
| 小型 | −1.30 (1.35)、非有意 | −0.83 (1.35)、非有意 | **未確認** |
| 中型 | +0.38 (0.78)、非有意 | **+2.00 (0.78)、原著p<.05** | **仮定つきで確認** |
| 大型 | +2.07 (1.26)、非有意 | **+4.86 (1.26)、原著p<.001** | **仮定つきで確認** |

同じ原著では、シナリオ間の二次係数の比較も中型・大型でp<.001。しかし「実際にδが0→1へ変化した集団」「同じ世代で雌雄異株の侵入が確認された」とは解釈できない。二次係数の差（小+0.47、中+1.62、大+2.79）は掲載値の**単純引き算**であって新しい検定ではない。

## 3. ここで見える自然史的な緊張：繁殖保証が、あとで干渉源になり得る

**雄がいないとき**：少数の雌に残った雄花形成能力は、雄がなくても雄性配分を増やす方向へ選択され、交配による子世代を残せた。ここで多機能性は繁殖保証に結びつく。

**両性機能が増えたとき**：雄花を多く作ることが花粉を獲得する力の増大だけではなく、同じ株の胚珠を自花粉で受精させる割合の増大にも結びつく。**自殖子孫の損失が強ければ**、一個体内で雄・雌を合わせる利点が相殺され、完全に雌的／雄的な極端配分が有利になり得る。実際、G8のδ=1仮定では中型・大型で二次係数が有意に正だった。

この**再分業の選択圧の候補**は2025年原著が既に報告した現象でありSLKが初めて発見したことではない。しかも2025年の実験は両性型の父性を測定したが、**再分業が集団中で進んだ／完全な雄・雌へ戻った結果はない**。原著は雌雄配分トレードオフの曲率について、生理的な分業利益が存在する可能性も論じており、「近交回避だけが実際の唯一の原因だった」と断定しない。

## 4. 形態はもう一つの履歴負担。2019年は独立試験

Santos Del Blanco, Tudor & Pannell (2019) [Ecology Letters, DOI 10.1111/ele.13207](https://doi.org/10.1111/ele.13207) は、別の自然集団由来の雌型に似た短い花序 (F-like) と雄型に似た長い花序 (M-like) の両性機能型について、**F-likeで父性獲得が約25%／31%低い**と報告。31%比較には両形態の自殖率が等しいという仮定が要る。これはG0→G8の同じ遺伝子型で花序形態を操作した結果ではなく、G8の近交弱勢と掛け算して「雌型復活個体の総適応度」を作れない。

**結論は3層に分ける。** (i) 他の雄が欠乏すると潜在的な雄花形成が選択を受け再発現することは実証済み。(ii) 再発現した機能は父性を獲得するが、個体の雄配分を増やすと自殖率が高くなる関連が実測され、**強い近交弱勢なら**再分業への選択が生じ得る。(iii) 専化した形態の履歴が父性に負担になることも別研究では示されたが、これらを同一の遺伝背景・生活史適応度・環境頻度下に統合した実験はない。

## 5. SLKとして残る本当の未解決問題（理論量の名前ではなく、生物の予測）

同じ遺伝的背景で雄の有無を再反転させたときに、**自殖による繁殖保証の便益と、近交弱勢・他殖父性競争・既存の花序形態の負担が、同一世代の成熟・生存子孫でどう入れ替わるか**。もし元の雌型花序を保ったまま雄機能の再発現が広がり、次の雄再導入下ではその花序が父性を制限するなら、構造を作り直す費用とパートナー環境が多機能性の持続をともに左右する可能性がある。逆に繁殖保証も父性負担も見られなければ、この特定の「履歴負担による状態依存的な維持」説は弱まる。

同じXXハプロタイプ、密度、雄頻度、花序形態、実父性、生存子孫の対照が必要。2021 G5は雄50%の1条件のみで希少侵入を測っていない。2025 G8は雄不在系列の子孫庭園であり、δ自体が実測されていない。2025のデータと2026のQTLは**同じ選択実験系列**に依存し、独立の進化起源を何件も数えない。

**新規性の境界：** これは「逆進化の初発見」でも「G0→G8で雌雄異株への再進化が起こった発見」でもない。生態学上の問いを、*失われた機能を戻せるか* から *戻った機能が異なる交配環境でなぜ維持・分化し得るか* に移す証拠の整理である。
