# SLK：雌雄分業の後でも、交配相手が消えると雌株は雄花形成を増やす

**2026-11-15｜実際の交配相手操作実験の原著検証。SLK PR #121の生物学的Draft限定。**

## 中心の生態学的な問い

**交配相手がいなくなった環境で、完全な雌雄分業をしている植物は、どうやって自らの繁殖機会を確保するのか。** これまでの `Sagittaria`・`Mercurialis` の集団間比較は、分業型の形成可能性とその生態学的な成功を区別してきた。今回、既刊の原著でさらに直接的な実証が見つかった。

*Cossard & Pannell（2021）*, *Journal of Evolutionary Biology* 34:416–422, DOI [10.1111/jeb.13720](https://doi.org/10.1111/jeb.13720)、[公開原著](https://academic.oup.com/jeb/article/34/2/416/7326544)。対象は**二倍体の自然雌雄異株 *Mercurialis annua***（XX雌／XY雄）で、先の2024年の六倍体CMS三性型とは遺伝背景・倍数性も性システムも異なる。

## 1｜交配相手を実際に排除することで、雌株の雄花形成が増える

35集団由来の共通混合種子から育てた苗を、スイスの屋外の**6実験集団**へ、ほぼ無作為に割り付けた。雄あり3集団（各雄90＋雌90）と、**雄なしの雌180のみの3集団**。共通温室で6週間育苗した後、実験処理を課して7週間育てた。結果として各集団から35〜50雌株、総計**272雌株**の生殖器官への投資を測定した。

| 原著結果 | 雄あり3集団 | 雌だけの3集団 |
|---|---|---|
| **雄花への相対的バイオマス投資 MRE** | 基準 | **2.33倍**（原著p=0.01） |
| 雄花形成がある雌株の**発生率** | 95パーセンタイルの閾値で**定義上5%** | 増加傾向だが原著p=**0.058**（有意ではない） |
| 雌花・果実への相対的な投資 FRE | 基準 | 有意な平均変化なし（原著p=**0.19**） |

雄花投資は**雄花乾燥重量／地上部の栄養器官乾燥重量**。したがって2.33倍を雄花の**個数の2.33倍、花粉の活性の2.33倍、自殖した子の2.33倍**と読み替えない。観察されたのは、**交配相手の構成という生態環境を操作した結果、XX雌株が形態的な雄性器官形成への資源投資を可塑的に増やした**という現象である。

一方、発生率のp=0.058は一般的な5%水準では有意でない。また、原著の「雄花を作る雌型」の判定は**対照集団の雄性配分MREの95パーセンタイル超**と事前定義されており、**対照5%は自然状態の雄花保持能力の真の絶対有病率を示す値ではない**。原著者は雄花を1つでも作る場合と80パーセンタイル閾値の場合も試し、概ね同じ方向と報告した。

## 2｜272個体を272回の独立な操作試行にしない

操作の実験単位は**6集団（各処理3）**であり、272雌株はそこにネストされる。原著は集団・鉢を混合モデルのランダム効果に含めている。

原著Methodsの採取内訳を計算すると、1鉢から1雌株のケースが192、2雌株が同一鉢にいるケースが13鉢、3雌株が同一鉢にいるケースが18鉢：

[
192+2\times13+3\times18=272\text{雌株}
]

測定個体のうち**80/272＝29.41%**は、同じ鉢にほかの測定個体がいる。異なる集団に入った苗は共通種子プール由来だが、**同じ遺伝子型のクローンを雄あり／なしに置いた遺伝子型対応の反応規準ではない**。原著の混合モデルのp値を、独立な同一遺伝子型の効果や祖先の遺伝的回復に格上げしない。

## 3｜雌機能を捨てるのではなく、環境に応じて別機能の器官形成を増やす

**雄なしで雄機能への配分が増え、FREの平均差は有意でなかった**ことから、「雌機能を減らして同じ量の雄機能に単純交換した」という説明は、この原著結果のみでは支持されない。しかし**雌機能の負担はゼロと証明できたわけではない**。資源コストを持っても効果が小さい可能性はある。

原著では同じ鉢にいる雄の数は、雌株のMRE（p=0.851）、FRE（p=0.977）、雄花形成発生率（p=0.11）と有意に関連しなかった。**隣の雄を直接認識している証拠はなく**、むしろ柱頭への花粉到着、果実形成などの生理的なシグナルを感知している可能性を著者らは提示する。**どのシグナルなのかは実験で判定されていない。**

さらに重要なのは、**形態的な雄花を作ったことと実際に受精能のある花粉を産出したこと、そこで自殖した子を遺伝子型で確認したこととは別**である。2021年原著の実験から雄花の花粉生存性や実際の自殖子数、長期の遺伝子頻度まで新しく計算できない。

**適応的な可塑性であることの決定的な検定も未完了**。原著者自身の要求は、雄がいないときに雄花を増やす反応型がより多くの子を残し、雄が十分いるときには反応しない型が優位になる、という**両環境における遺伝的繁殖成功の交差**を実測すること。ここはSLKの機能的な分業と多機能性が残る条件の問いそのもの。

## 4｜同じ種名でも2xと6xを混ぜず、自然界での共通問題にする

- **2021年（2x）**：XX雌／XY雄の雌雄異株。雄の欠如という**直接の操作**で、雌株が雄花に投資する量は2.33倍。もともと持っている発生能力の環境依存的発現。
- **2024年（6x）**：雌・雄・雌雄機能型が同じ集団にいる。雌型は**形態的な雄花を残したまま、雄機能が不稔**になる例が多い。別の0.5〜1.5mの実験では、非結実雌花の割合が雌型で+5.3ポイント、距離1m当たり+8.4ポイント（[原著2024距離実験](SLK_MERCURIALIS_2024_SPATIAL_POLLINATION_STAGE_FILTER_V5_20261115.md)）。後者は**非結実による推定送粉制約**で、直接の花粉粒数ではない。

二つを「同じ遺伝子型で雄機能を失い、その後遺伝的に再獲得した」と結んではいけない。**雄性器官の形態が残ること、雄花形成能力が可塑的に増えること、実際の父性成功が得られること**は進化学上は別の階層にある。

### Island・ANTOとの接続は検証仮説に限定

2021年原著は、交配相手の少ない入植時、とくに島への定着を考察している。ただし実験はスイスの共通庭園とスペイン由来の遺伝背景で行われ、**島嶼集団の独立な実測ではない**。むしろ生物学的予測として、雌雄分業した植物が島へ少数個体で入った際、雌型の偶発的雄花形成能力が残っていれば繁殖保証に役立つ可能性がある。

ANTOで考える器官の残存についても、**形成できる形態、成熟した機能、父性・母性の適応度、遺伝的制御の保存**を区別する必要がある。現存する雄花の可塑性をもって、一度消失した雄機能が遺伝的に再進化したとは言わない。
