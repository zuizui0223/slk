# SLK：分業の利益はどの繁殖段階で消えるのか

2026-11-16。公開原著の段階別実証統合。Draft PR #121のみ。主論文・main・ANTO・aza3は変更しない。

## 中心問題

機能間の葛藤を構造・時間・個体間の分業で緩和しても、その利益は次世代の遺伝的成功へ伝わるのか。分業による一段階の改善を「総適応度の改善」と誤認しない。**段階別ボトルネックが、分業の生態的利益を制限する**という比較仮説を検証可能な形にする。

## どこが実証で、どこが未解決か

- **介入が成熟種子まで届く例**：Cyananthusの花粉除去。花の内部の時間的競合を解除することで母性種子が回復した。父性は未測定。
- **同一研究内の近位指標と下流指標の非一致**：Mercurialis六倍体2024年の非結実割合と種子バイオマスの有意性の差。ただし一方が有意・他方が非有意であること自体は、効果間の有意な差を証明しない。
- **別集団の強い逆順位**：Wurmbeaの訪花と種子／胚珠。観測時期・性型・資源などの交絡があり、単一の訪花→種子変換率を計算しない。
- **機会から父性への欠落**：Sagittariaの訪問経路代理と実際の父性は異なる研究。両者の因果媒介を統合推定しない。
- **再発現から遺伝的父性への到達**：Mercurialis二倍体。2021年の子性比推定と2025年のSSR父性は別世代・異なる推定量。近交弱勢込みの生涯遺伝適応度は未実測。

## 次に検証すべき生態学的予測

**P1: 分業の近位利益が大きいほど総繁殖利益が大きい、という単調関係は一般には成立しない。** 真の同一個体・同一実験で訪花／花粉受領／種子／父性／実生を縦断測定して初めて検定できる。既刊の非対応集計から媒介係数は推定しない。

**P2: 制約の所在は分業の階層によって変わる。** 同じ花の時間分業では雄相→雌相の機会、同株の別花では自殖と資源配分、別個体分業では相手との空間的花粉輸送が候補。各機構が普遍的に支配的だとは主張しない。

**P3: 機能が再出現しても、相手頻度・形態履歴・近交弱勢が実現する遺伝的利益を左右する。** 同じ遺伝背景で雄頻度・密度・形態を交差させ、実父性と成熟・生存子孫を測る必要がある。

## 対立仮説と反証

1. **資源制限だけで説明**：資源を統制すれば性型や相手構成による種子の差は消える。
2. **花粉量制限だけで説明**：十分な他家花粉を補充すれば性型・距離・送粉者経路の下流差は消える。
3. **交配の質が主因**：同じ花粉量でも自殖／他殖構成と子孫生存で差が残る。
4. **配偶者の空間配置が主因**：総個体数を固定しても配置・距離を変えると実父性が変わる。
5. **形態履歴が主因**：同一背景で花序構造を操作すると、父性の制約が解消するかを問える。

**研究上の最も厳しい区別**：近位の改善と下流の非有意性は、それだけで「変換段階の遮断」の統計的証明ではない。遮断を結論づけるには、対応したデータ、媒介・交互作用の識別、十分な精度が要る。

## 論文上の推奨

SLK主稿の核は引き続き「葛藤はいつ分業を生み、なぜ多機能性が残るのか」。この実証補助線は「分業の選択価値を決めるのは、近位機能ではなく**次世代への実際の遺伝的伝達**」という生態学的な論点に限定する。現在の比較は原著結果のsource-audited synthesisであり、新規の横断的因果解析、独立メタ解析、SLKのPhi/g0/Delta_R実測ではない。
