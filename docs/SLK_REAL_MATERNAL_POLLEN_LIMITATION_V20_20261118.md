# SLK V20｜多機能型は「種子を多く作る」のではなく「花粉制限を弱める」のか

**2026-11-18｜Nguyen, Martignier & Pannell (2024) *American Journal of Botany* 原著の実測を生態学的に再評価。既刊の実証の再整理であり新規の原データ検定ではない。Draft PR #121のみ。**

## 生物学的な肯定結果

原著 DOI [10.1002/ajb2.16429](https://doi.org/10.1002/ajb2.16429) は、六倍体 *Mercurialis annua* の**雌型Fと両性型Hの花粉制限を同一研究内で比較**している。実際に得られた重要な結果は：

1. **種子生産はFとHの両方で花粉制限を受ける。** 原著 LMM t=4.45, df=66, p<.001。
2. **雌型Fは両性型Hより花粉制限が強い。** 原著 t=2.23, df=66.1, p=.029。
3. **Fの雌性投資はHを大きく上回らない。** 種子数/バイオマスの差の原著p=.097、繁殖努力の差p=.55。原著の検出力評価ではFの種子生産がHの1.12倍を超えるような大きな差は考えにくいが、**厳密な同等性検定や「全く費用なし」の証明ではない**。

**中心となる生態学的な読み方：** 専門化した雌が必ずしも多くの種子を作らない一方、花粉供給が制限される環境では、雄機能を持つHの方が**花粉不足への脆弱性が小さい**。これはSLKが問う「分業によって新たに生じる他個体依存性」を、同一六倍体系の実際の受粉・種子実験で支える既刊の肯定結果である。

## 2024年リング実験との統合：同一論文、別の測定

同じ2024年原著のリング配置では、H母株の雄型子割合は雄から離れると大きく低下（中心188/491、遠方41/325）。欠測最悪割当でも中心と遠方の差は18.90ポイント以上（既存V12–V14）。母株当たり雌花1個の**実験室推定発芽子数**は中心→遠方でF 0.916→0.626、H 0.916→0.785（既存V11/V15）。ただしH−Fの距離交互作用は既存母株bootstrap95%区間がゼロを含む。

**花粉制限の原著実験とリング配置は同一原著の関連実験であり、独立の再現研究とは数えない。** 前者のF対Hの花粉制限差p=.029は原著が検定した結果であり、リングの発芽子数交互作用が有意になったという意味ではない。

## この結果で強められる主張／強められない主張

| 生態学的な主張 | 状態 |
|---|---|
| 雌型Fは両性型Hより花粉不足の影響を強く受ける | **原著で支持**（p=.029） |
| Fの種子生産能力はHを大きく上回る | **原著で支持されない**（p=.097、検出力評価あり） |
| 雄の少ない環境でHの母性繁殖成果が相対的に保たれる | **リングの記述傾向は整合**、交互作用CIはゼロを含む |
| Hは自殖によってFを救済的に凌駕した | **未同定**。実父性・自殖率のDNAデータなし |
| 多機能性の長期的な適応度維持は花粉制限のためである | **未実証**。CMS/核回復遺伝子・近交弱勢・実生生存も関与し得る |

**競合する生物学的機構を残す：** 雌型の花粉制限の強さは、外部花粉の受容・開花時期・母株背景・配偶子品質などでも変わる。Hの自殖が観測されたと同定してはいけない。原著のCMSと核回復遺伝子のモデルは、花粉制限と独立にも三性型共存を生み得る。花粉制限による短期の繁殖保証と遺伝的頻度依存維持は別軸である。

## 他の2021・2025年研究との関係

- Cossard & Pannell (2021 JEB; DOI 10.1111/jeb.13720) の二倍体・雄なし処理は雌の雄花配分を2.33倍にするが、雌性配分減少p=.19で未確認。**雄花の発現と母性繁殖保証は同一実験で結びついていない**。
- Chen & Pannell (2025 *New Phytologist*, DOI [10.1111/nph.70356](https://doi.org/10.1111/nph.70356)) は、別の二倍体実験進化系で**雄性・雌性配分の表現型トレードオフと、花粉生産が多い個体ほど自殖率が高い関係**を示した。高い近交弱勢を**仮定した**シナリオで分断選択が強くなるが、実際の近交弱勢強度や生涯適応度の比較がすべて実測されたわけではない。これはすでに既刊で、SLK独自の発見ではない。
- 2012年の三性型実験では雄の有無×母株型の種子投資応答が異なった（原著F(1,445)=6.3, p<.05）。種子への**配分率**と実際の遺伝的次世代寄与は区別する。

## SLKにとって最も生物学的な一文

**分業した雌は、必ずしも多機能型より種子を多く作るわけではない。それでも他個体の花粉に依存するため、花粉が制限されると多機能型より強く繁殖が制約される。この「分業が作る依存性」は自然植物の操作実験で支持されている。ただし、その依存性が長期的な分業の維持／崩壊を決める因果過程はまだ解明されていない。**
